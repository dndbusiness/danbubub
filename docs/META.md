# חיבור Meta (פייסבוק) — עלויות הקמפיינים

המערכת **קוראת** עלויות בלבד: כמה הוצא בכל קמפיין, בכל חודש, וכמה לידים Meta ספרה. היא לא יוצרת ולא משנה מודעות.
לכן מספיקה ההרשאה `ads_read`, ואין צורך ב-`ads_management`.

- **חשבון המודעות:** `2166211937175095` (ב-API: `act_2166211937175095`). Business ID: `1077021437284220`.
- **חשבון אחד לשתי החברות:** כל קמפיין משויך לחברה לפי השם שלו.
  - "נדל"ן", "השקעות", "פריסייל" → הר-אל השקעות.
  - כל השאר → הר-אל פתרונות. גם "נכסים" נחשב פתרונות, כי זו הלוואה כנגד נכס.
  - אפשר לתקן חברה של קמפיין ב"עריכה" שלו, והתיקון נשמר.
- **הקוד:** `lib/rules/meta.ts` (`divisionOfCampaign`, `metaAccounts`), `app/api/crm/meta/route.ts`.

1. https://business.facebook.com ← **הגדרות העסק** (Business Settings) ← בתפריט **משתמשים** ← **משתמשי מערכת** (System Users).
2. **הוספה** (Add):
   - שם: `harel-crm`
   - תפקיד: **עובד** (Employee). אין צורך במנהל.
   - **יצירה**.
3. על המשתמש שנוצר ← **הקצאת נכסים** (Assign Assets) ← **חשבונות מודעות** ← מסמנים את **2166211937175095** ← הרשאה **צפייה בביצועים** (View performance) ← **שמירה**.
4. **יצירת אסימון** (Generate New Token):
   - בוחרים אפליקציה. אם אין: developers.facebook.com ← **My Apps** ← **Create App** ← סוג **Business** ← שם `harel-crm`, ואז חוזרים לכאן.

   - **הרשאות:** מסמנים **ads_read** בלבד.
   - **יצירה** ← מעתיקים את האסימון. הוא מוצג פעם אחת.

### 3. בדיקה
- במערכת: **שיווק** ← **קמפיינים** ← **"משוך עלויות מפייסבוק"**.
- **תקין:** תוך כמה שניות מופיעים הקמפיינים מ-Meta, עם תגית החברה, ההוצאה חודש-חודש ועלות ממוצעת לליד.
- **שגיאה:** הסיבה מופיעה ליד הכפתור. הסיבות הנפוצות: אסימון לא נכון, או שהמשתמש לא שויך לחשבון.
- **שמות קמפיינים:** אם שם קמפיין ב-Meta שונה מהשם שמופיע בלידים, מוסיפים את השם מהלידים ב"עריכה" של הקמפיין, בשדה "הלידים שלו מגיעים בשם". כך העלות מתחברת ללידים.
