# וויאסנטר ↔ מערכת הר-אל

לפי האפיון של דן (20/10): CDR, חיוג מהמערכת (Click2Call), Pop-Up, ניתוב חכם, VoiceBot, חייגן ו-Lead Tracker.

**מה בנוי (20/10):** שלב 1 (CDR), שלב 2 (חיוג), שלב 3א (Pop-Up).
**מה מחכה לפרטים מדן:** 3ב, 4, 5, 6 — ראו בסוף.

## איך זה בנוי — התאמה למה שכבר קיים

נתוני ה-CRM יושבים ב-`crm_docs`. אין טבלאות SQL חדשות, כי במסד שכבר הוקם אין דרך להריץ migration מהדפדפן (הנחיה 10).

| באפיון | אצלנו |
|---|---|
| `calls` | `calls/<ivruniqueid>` — upsert לפי המזהה (וויאסנטר שולחת כל CDR פעמיים) |
| `voicenter_events` | `vcEvents/<id>` — הבקשה הגולמית + `processed` / `error`. לא יוצא לדפדפן (`SERVER_ONLY`) |
| `leads.last_call_at`, `calls_count` | `leads.lastCallAt`, `leads.callsCount`, ו-`leads.calls[]` — הרשומה שהדף כבר מציג ומונה |
| `users.voicenter_extension` | `settings.users[].ext`, ולדן `settings.ownerExt`. מיפוי ידני (שם או קוד נציג): `settings.voicenterReps` |

- **פונקציות טהורות:**
  - `lib/rules/voicenter-cdr.ts` — פענוח CDR (case-insensitive), שעון ישראל, legs, Pop-Up, Click2Call. נבדק ב-`tests/voicenter-cdr.test.ts`.
  - `lib/rules/voicenter.ts` — שלוחה → עובד.
- **מסד:** `lib/crm/voicenter.ts`.
- **טלפונים:** `normPhone` (`lib/crm/inbound.ts`) — אותה פונקציה בכל מקום: 0501234567.
- **זמן:** `time` ב-CDR הוא epoch של שעון הקיר בישראל. ההמרה ל-UTC נעשית ב-`israelWallEpochToIso` (קיץ ‎+3, חורף ‎+2).

## הכתובות

| כתובת | מי קורא | הגנה |
|---|---|---|
| `POST /api/voicenter/cdr?key=…` | וויאסנטר, בסוף כל שיחה | `VOICENTER_WEBHOOK_SECRET` (השוואה timing-safe). עונה `{"Err":0,"Errdesc":"OK"}` |
| `POST/GET /api/voicenter/popup?key=…` | התוסף של וויאסנטר בכרום | אותו מפתח. רק ב-Ringing |
| `POST /api/voicenter/call` | הדף ("☎ מהמרכזייה") | כניסה למערכת. `VOICENTER_CODE` לא יוצא לדפדפן |
| `GET /api/voicenter/extensions` | ההגדרות (דן) | כניסה כדן |
| `/api/crm/inbound/voicenter`, `/api/crm/call` | הכתובות הקודמות | ממשיכות לעבוד, עם אותו עיבוד |

### שלב 1 — מה קורה עם כל שיחה

1. הבקשה נשמרת גולמית ב-`vcEvents`.
2. השיחה נשמרת ב-`calls/<ivruniqueid>`. שליחה כפולה לא יוצרת שורה נוספת.
3. **זיהוי הלקוח:**
   - `var_leadId` (מהחיוג) גובר על הכול.
   - אחרת, לפי הטלפון: בשיחה נכנסת המתקשר, ביוצאת היעד. קודם מחפשים ליד, ואם אין — לקוח.
4. **שיחה נכנסת ממספר לא מוכר** → ליד חדש "שיחה נכנסת <מספר>", עם המקור "שיחה נכנסת". החברה נקבעת לפי ה-DID מ-`settings.vcDidDivision`; ברירת המחדל היא פתרונות.
5. **Click2Call:** leg1 (הצלצול לנציג) נשמר ומסומן מוסתר. רק leg2 נכנס לכרטיס.
6. **הנציג:** לפי השלוחה, אחרת לפי שם או קוד הנציג.
7. **שיחה נכנסת שלא נענתה** → משימה "לחזור ללקוח" לאחראי על הליד, בעדיפות גבוהה ולהיום. `ruleKey = vc-missed:<ivr>`, כך שיש רק משימה אחת לכל שיחה.

**במסך:**
- בכרטיס ליד ובכרטיס לקוח — "שיחות": כיוון, נציג, משך, סטטוס בעברית, נגן הקלטה + "פתח הקלטה", וסיכום AI אם יש.
- לידים ← "שיחות": סינון לפי נציג, מצב ותאריכים, וכפתור "שיחות שלא נענו היום".

### שלב 2 — חיוג מהמערכת

- **הכפתור "☎ מהמרכזייה"** נמצא בטבלת הלידים, בכרטיס ליד ובכרטיס לקוח.
- **הבקשה:** `POST https://api.voicenter.com/ForwardDialer/click2call.aspx` (JSON) עם `record`, `checkphonedevicestate`, `var_leadId` / `var_clientId` / `var_userId`.
- **תשובות:** שגיאות 0–4 מוצגות בעברית.
- **פס "מחייג…":** מופיע עם כפתור "נתק" (`action=terminate`).
- **נעילה:** הכפתור ננעל ל-5 שניות אחרי לחיצה.
- **בלי שלוחה:** בכרטיס מופיע "לא הוגדרה שלוחה".
- **בחירת שלוחה:** בהגדרות ← משתמשים, השדה "שלוחה במרכזייה" מציע את השלוחות מהחשבון (Organizational Extension List).

### שלב 3א — Pop-Up

- **ליד קיים:** מחזירים `{"STATUS":"OK","URL":".../crm#lead:<id>","CLIENTNAME":…,"TOTAL":…,"COMPANY":"שלב: … · אחראי: …"}`.
- **מספר לא מוכר:** הקישור `#newlead:<טלפון>` פותח "ליד חדש" עם הטלפון ממולא.

## מה דן עושה — צעד אחר צעד

### א. שני משתנים ב-Vercel (פעם אחת)
1. Vercel ← הפרויקט **danbubub** ← **Settings** (הגדרות) ← **Environment Variables** (משתני סביבה) ← **Add New** (הוספה).
2. **משתנה ראשון:**
   - Key (שם): `VOICENTER_WEBHOOK_SECRET`
   - Value (ערך): המחרוזת שקיבלת ממני בצ'אט.
   - מסמנים Production ← Save (שמירה).
3. **משתנה שני:**
   - Key (שם): `VOICENTER_CODE`
   - Value (ערך): הקוד מוויאסנטר — ראו ב' בהמשך.
   - Production ← Save.
4. **Deployments** (פריסות) ← בשורה העליונה **⋯** ← **Redeploy** (פריסה מחדש). אם זה נתקע — **Promote**.

### ב. איפה הקוד של וויאסנטר (VOICENTER_CODE)
1. נכנסים ל-CPanel של וויאסנטר ← בתפריט **API** ← **קליק2קול** (Click2Call).
2. בעמוד יש כתובת לדוגמה עם `code=` ואחריו אותיות ומספרים. מעתיקים **רק את מה שאחרי `code=`**, עד הסימן `&` הבא או עד הסוף.
3. מדביקים ב-Vercel כערך של `VOICENTER_CODE` (א' שלב 3).

### ג. כתובת CDR שנייה (שלב 1) — בלי לגעת בכוורת
1. CPanel ← **API** ← **היסטוריית שיחות** ← הלשונית **"כתובת CDR חיצונית"**.
2. רואים שם את השורה של כוורת (`callcenter.kaveret.biz…`). **לא נוגעים בה.**
3. לוחצים **"+ להוסיף"**.
4. **כתובת:** מדביקים בדיוק את זה, ובמקום `<המחרוזת>` את המחרוזת מסעיף א':
   `https://danbubub.vercel.app/api/voicenter/cdr?key=<המחרוזת>`
5. **טכנולוגיה:** JSON. **סטטוס:** מופעל ← שמירה.
6. **בדיקה:**
   - מתקשרים מהנייד למספר של המשרד ומנתקים.
   - תוך דקה השיחה מופיעה במערכת: לידים ← "שיחות", ובכרטיס הליד.
   - ב-CPanel ← היסטוריית שיחות ← **"יומן CDR חיצוני"** — הכתובת שלנו מחזירה 200.

### ד. שלוחה לכל עובד (שלב 2)
1. במערכת: **הגדרות** ← **משתמשים והרשאות**.
2. לכל עובד: **עריכה** ← **"שלוחה במרכזייה"**. אחרי שהקוד מוגדר, ברשימה מופיעות השלוחות מהחשבון, למשל SIP…. בוחרים ← **שמור**.
3. השלוחה שלך: בשורה "המייל של דן להתראות" ← **"השלוחה של דן במרכזייה"** ← **שמור**.
4. **בדיקה:**
   - נכנסים לליד ← **"☎ מהמרכזייה"**.
   - השלוחה שלך מצלצלת. עונים, ואז הלקוח מחויג.

### ה. Pop-Up — כרטיס קופץ בשיחה נכנסת (שלב 3א)
1. בכרום: חנות האינטרנט של Chrome ← מחפשים **"Voicenter Chrome Extension"** ← **הוספה ל-Chrome**.
2. CPanel ← **API** ← **הגדרות תוסף Chrome** ← **הגדרות פרופיל** ← **"+ להוסיף"**.
3. **כתובת:**
   `https://danbubub.vercel.app/api/voicenter/popup?key=<המחרוזת>`
4. **בדיקה:** בשיחה נכנסת קופצת הודעה עם שם הליד, השלב והאחראי. לחיצה עליה פותחת את הכרטיס.
