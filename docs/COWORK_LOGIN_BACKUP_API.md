## משימה 2 — כניסה בקוד לנייד / למייל

בגרסה החדשה מסך הכניסה מציג **"שלחו לי קוד"**:

- **איך נכנסים:** מקלידים שם משתמש (דן משאיר ריק), מקבלים קוד בן 6 ספרות, ונשארים מחוברים 14 יום.
- **לאן נשלח הקוד:**
  - **וואטסאפ** — רק אם Green API מחובר (משימה 3א) ויש מספר נייד בהגדרות.
  - **מייל** — רק אם גוגל מחובר עם הרשאת שליחת מייל (משימה 3ב).
    - עובד בלי מייל משלו מקבל את הקוד ל-`finance@harelinvest.co.il`.
    - דן מקבל את הקוד למייל של דן מההגדרות.

**מה Cowork ממלא במערכת** (הגדרות ← משתמשים והרשאות):

1. בשורת "המייל של דן להתראות":
   - הנייד של דן.
   - "מייל לקודי כניסה" = `finance@harelinvest.co.il`.
   - שמור.
2. לכל עובד ← "עריכה":
   - **נייד** — מספר הוואטסאפ שלו.
   - **מייל** — אם יש לו מייל אישי. ריק = finance@.
   - שמור.
3. **בדיקה:**
   - "יציאה" למעלה.
   - במסך הכניסה, בלי שם משתמש ← "שלחו לי קוד".
   - הקוד מגיע לנייד או למייל של דן ← מקלידים ← נכנסים.

## משימה 3 — חיבורי API (Vercel ← danbubub ← Settings ← Environment Variables ← Production)

**לפני שמתחילים:** בודקים מה כבר קיים ברשימה, ומוסיפים רק מה שחסר. אחרי כל הוספה: Deployments ← האחרון ← ⋯ ← **Redeploy**.

> אם הבנייה נתקעת על "Waiting for checks" — לוחצים **Promote** / **Force Promote**.

### 3א — וואטסאפ (Green API): קודי כניסה, התראות נוכחות, תזכורות, חתימות

1. https://green-api.com ← הרשמה (דן) ← Create instance ← מסלול **Developer** (חינם).
2. **סריקת QR:** סורקים מהטלפון של המשרד. וואטסאפ ← מכשירים מקושרים ← קישור מכשיר.
   - המספר הזה ישלח את ההודעות.
3. מהדף של ה-instance:
   - `GREEN_API_ID_INSTANCE` = **idInstance**. זה לא סוד, Cowork מזין.
   - `GREEN_API_TOKEN` = **apiTokenInstance**. **דן מדביק.**
4. **בדיקה:** אחרי Redeploy, משימה 2 ← "שלחו לי קוד" ← ההודעה מגיעה בוואטסאפ.

### 3ב — גוגל: מייל, יומן, דרייב

- **אם כבר מחובר:** https://danbubub.vercel.app/settings ← כרטיס גוגל מציג חשבון מחובר עם הרשאת מייל. מדלגים.
- **אם לא:** לפי `docs/GO_LIVE_COWORK.md` שלב 6.
  - `GOOGLE_CLIENT_ID` — Cowork.
  - `GOOGLE_CLIENT_SECRET` — **דן מדביק**.
  - Redirect: `https://danbubub.vercel.app/api/google/callback`.
  - `APP_BASE_URL` = `https://danbubub.vercel.app`.
- **בדיקה:** בכרטיס גוגל מופיע החשבון ו-"שליחת מייל".

### 3ג — שאר המשתנים

| משתנה | מי | למה |
|---|---|---|
| `SECRETS_KEY` | דן | חובה (עוגיות כניסה, טוקן גוגל). **אם כבר קיים — לא לשנות!** שינוי ינתק את כולם ואת גוגל |
| `SIGN_SECRET` | דן | חתימות דיגיטליות |
| `OWNER_EMAIL` | Cowork | המייל של דן (לשאול) |
| `CHROMIUM_PACK_URL` | Cowork | PDF בשרת — הערך ב-`docs/DEPLOY.md` §3 |
| `ANTHROPIC_API_KEY` | דן | ניתוחי AI. בנוסף `AI_DAILY_ILS` = `15` (Cowork) |
| `LEADS_API_KEY` | דן | קליטת לידים ממערכות חיצוניות (אקראי, 32+ תווים) |
| `VOICENTER_SECRET` | דן | שיחות מ-Voicenter, אם בשימוש |

**בדיקה סופית:**

- https://danbubub.vercel.app/api/health = תקין.
- https://danbubub.vercel.app/settings ← "בריאות המערכת" בלי אדום.
- מדווחים לדן איזה משתנה נוסף ואיזה עדיין חסר.
