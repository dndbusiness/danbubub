# חיבור Claude למערכת — מדריך מסודר

יש **שתי דרכים** לחבר את Claude. אפשר לחבר אחת מהן או את שתיהן, ומומלץ את שתיהן.

| | דרך 1: מפתח API (בתשלום) | דרך 2: התור על המנוי (חינם) |
|---|---|---|
| **מה זה** | השרת פונה ל-Claude ישירות | שגרה של Claude Code עונה על בקשות שמחכות בתור |
| **מהירות** | שניות | עד 10 דקות (או עד שעה) |
| **עלות** | לפי שימוש, עם תקרה של **15 ₪ ליום** (אישרת ב-16/10) | נכלל במנוי Claude שלך |
| **מה זה מפעיל** | שווי רכב מיידי (יד 2), דוח אשראי, "מלא שדות", סריקת מסמך, חילוץ חשבונית של ספק לא מוכר | ניתוח תיק, הערכת שווי נכס (עם חיפוש ברשת). גם דוח אשראי וסריקה כשנגמרת התקרה |
| **בלי זה** | אין שווי רכב מיידי. החילוץ מחשבוניות נעשה לפי כללים בלבד | אין ניתוח תיק ואין הערכת שווי נכס, והכפתורים מוסתרים |

**חשוב בשתי הדרכים:** כל מה ש-Claude מחזיר הוא **הצעה בלבד**. אדם מאשר במערכת לפני שזה נשמר (הנחיה 17).

## דרך 1 — מפתח API (5 דקות)

### שלב 1: יוצרים מפתח (דן)

1. נכנסים ל-https://console.anthropic.com ומתחברים עם המייל שלך.
2. **Billing** (חיוב) ← מוסיפים כרטיס אשראי ← **Add credit** (הוספת קרדיט).
   - מספיקים **10–20 דולר** להתחלה.
   - מומלץ לסמן **Auto-reload כבוי**, כדי שלא יחויב לבד.
3. **Settings ← Limits** (הגדרות ← מגבלות): מגדירים **Monthly spend limit** (תקרת הוצאה חודשית) של **150 דולר**.
   - זו שכבת הגנה שנייה, מעל התקרה היומית של המערכת.
4. **API Keys** (מפתחות) ← **Create Key** (יצירת מפתח):
   - שם: `harel-danbubub`.
   - לוחצים **Create** ← **מעתיקים את המפתח**. הוא מתחיל ב-`sk-ant-`.
   - ⚠️ המפתח מוצג **פעם אחת בלבד**. שומרים אותו במנהל הסיסמאות. לא שולחים בצ'אט, בוואטסאפ או במייל.

### שלב 2: מכניסים את המפתח למערכת (דן, או קו ווארק עם דן)

1. https://vercel.com ← הצוות `dndbusiness-projects` ← הפרויקט **danbubub** ← **Settings ← Environment Variables**.
2. **Add New** (הוספה):
   - **Key** (שם): `ANTHROPIC_API_KEY`
   - **Value** (ערך): **דן מדביק** את המפתח מ-שלב 1.
   - **Environment**: לסמן **Production** בלבד.
   - **Save**.
3. **Add New** שוב:
   - **Key**: `AI_DAILY_ILS`
   - **Value**: `15`
   - **Environment**: Production ← **Save**.
4. **Deployments** ← הבנייה העליונה ← **⋯** ← **Redeploy** ← **Redeploy**.
   - אם נתקע על "Waiting for checks" ← **Promote**.

### שלב 3: בודקים שזה עובד

1. https://danbubub.vercel.app/crm ← **הגדרות** ← כרטיס **"Claude API — ניצול"**:
   - מופיעה התקרה (15 ₪) וכמה נוצל היום.
2. **בדיקה אמיתית:**
   - פותחים ליד או לקוח שיש לו רכב ← **"שווי מיידי"** ← מגיעה תשובה תוך כמה שניות.
3. **בדיקה מהשרת:** `node scripts/preflight.mjs` כבר לא מציג "ANTHROPIC_API_KEY לא מוגדר".

### מה קורה כשנגמרת התקרה

- **ביום:** אחרי 15 ₪ בקשות דחופות עוברות לתור (דרך 2). אם התור לא מחובר — מופיעה הודעה, ושום דבר לא נשבר.
- **מחר:** התקרה מתאפסת לבד.
- **שינוי התקרה:** משנים את `AI_DAILY_ILS` ב-Vercel ועושים Redeploy.

### אם צריך לבטל

- **מנתקים את המערכת:** מוחקים את `ANTHROPIC_API_KEY` ב-Vercel ← Redeploy. המערכת חוזרת לעבוד בלי Claude API.
- **המפתח דלף:** ב-console.anthropic.com ← API Keys ← **Disable** על המפתח, ויוצרים חדש.

## דרך 2 — התור על המנוי (10 דקות, פעם אחת)

שגרה של Claude Code רצה כל 10 דקות, מושכת בקשות מהמערכת, עונה עליהן ומחזירה את התשובה לתיק.

### שלב 1: סביבה עם המשתנים (דן)

1. https://claude.ai/code ← למטה ← **Environments** (סביבות) ← **Default** ← **Edit** (עריכה) ← **Environment variables** (משתני סביבה).
2. מוסיפים, כל אחד בשורה:
   ```
   APP_BASE_URL=https://danbubub.vercel.app
   APP_PASSWORD=<קוד הכניסה למשרד — דן מקליד>
   JOBS_SECRET=<אותו ערך כמו ב-Vercel — דן מקליד>
   AI_QUEUE_EVERY_MIN=10
   ```
   - **אם אין `JOBS_SECRET` ב-Vercel:**
     - יוצרים מחרוזת אקראית ארוכה (32+ תווים).
     - מוסיפים אותה **גם** ב-Vercel (Production) **וגם** כאן, באותו ערך.
     - עושים Redeploy ב-Vercel.
3. **Save**.
4. **Network access** (גישה לרשת) של הסביבה: לוודא שמותר לגשת ל-`danbubub.vercel.app`.
   - אם הגישה מוגבלת — מוסיפים את הכתובת לרשימת המותרים.

### שלב 2: יוצרים את השגרה (דן)

1. https://claude.ai/code ← **Routines** (שגרות) ← **New routine** (שגרה חדשה).
2. ממלאים:
   - **Repository** (ריפו): `dndbusiness/danbubub`.
   - **Environment**: Default (זו מ-שלב 1).
   - **Schedule** (תזמון): כל 10 דקות. אם לא מאפשר — כל שעה, ואז לשנות בסביבה את `AI_QUEUE_EVERY_MIN=60`.
   - **New session each run** (סשן חדש בכל ריצה): כן.
   - **Allowed tools** (כלים מותרים): לסמן **WebSearch** ו-**WebFetch**. זה בשביל הערכת שווי נכס בלבד.
3. **Prompt** (ההנחיה) — מעתיקים כמו שהיא מ-`docs/AI_QUEUE.md`, מהקטע "ההנחיה לשגרה".
   - **מה מוחקים:** את סעיף 2 שם (`git checkout claude/new-session-3k3pta`). הקוד כבר ב-main.
4. **Save** ← **Run now** (הרץ עכשיו).

### שלב 3: בודקים שזה עובד

1. הריצה הראשונה מסתיימת בשורה כמו "אין בקשות בתור". זה תקין.
2. **בתוך 10 דקות:** במערכת ← כרטיס לקוח ← מופיע הכפתור **"נתח את התיק"**. הכפתור מופיע רק כשהתור חי.
3. לוחצים עליו ← "בתור…" ← אחרי הריצה הבאה מופיע ניתוח בכרטיס "ניתוחי Claude".

### שימו לב

- **מכסת המנוי:** כל ריצה צורכת קצת מהמכסה, גם ריצה ריקה. בשבוע הראשון כדאי לבדוק שהמכסה מספיקה.
- **אם השגרה נעצרת:** הכפתורים נעלמים לבד אחרי חצי שעה. בקשה שלא נענתה תוך 3 שעות נסגרת כנכשלה.
- **מה השגרה לא עושה:** לא שולחת מיילים ולא הודעות, לא משנה קוד, ולא נוגעת בשום דבר מלבד תשובה לבקשה.
