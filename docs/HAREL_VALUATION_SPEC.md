## 0. בשורה אחת

הר-אל צריכה שני מוצרים, לא אחד:

1. **בדיקה ראשונית** — כמו דירובוט, אבל נכונה יותר ושקופה.
   - כתובת + 4 פרטים, ובתוך דקה: טווח שווי, עסקאות דומות, מחירי יזמים, שכירות, ואחוז מימון.
   - מתאים לדירה בבניין, בשיחת המכירה הראשונה.
2. **בדיקה מעמיקה** — "טרום-שמאות".
   - עוברת על כל מה ששמאי בודק: זכויות, תכנון, היתרים, חריגות, מגרש ושכירויות.
   - מוציאה שווי, שווי מימוש מהיר, ושווי נטו כבטוחה לבנק.
   - **ובעיקר: רשימת הבעיות שהשמאי של הבנק ימצא — לפני שהוא מוצא אותן.**

**הבדיקה על המסמכים שהעלית (סעיף 9) מראה למה צריך את שניהם:**
- בבית צמוד קרקע, חציון העסקאות הדומות יצא **15% מתחת** לשמאות בפועל.
- דירובוט הוציא באחד הדוחות שווי שגבוה ב-83% מהעסקה היחידה בבניין — וגם סתר את עצמו בתוך הדוח.

## 4. שני המסלולים

| | **בדיקה ראשונית** | **בדיקה מעמיקה** |
|---|---|---|
| למי | נציג בשיחה ראשונה, ליד חדש | מטפל תיק לפני הזמנת שמאי, ותיקים מורכבים |
| כמה שאלות | 4 חובה + 3 רשות | 30–60, לפי סוג הנכס |
| זמן | פחות מדקה | 15–30 דקות + מסמכים |
| מסמכים | אין | נסח / אישור זכויות, גרמושקה, היתרים, חוזי שכירות, תשריט |
| שיטה | עסקאות דומות → חציון ₪/מ"ר → טווח | עסקאות דומות **עם התאמות פרטניות** (כמו שמאי) + גישת עלות לצמודי קרקע + דגלים משפטיים ותכנוניים |
| פלט | טווח, ביטחון, עסקאות, יזמים, שכירות, אחוז מימון | כל זה + שווי מימוש מהיר + **שווי נטו כבטוחה** + ערך כינון + מיסים צפויים + **רשימת "מה השמאי ימצא"** |
| דוח | 2–3 עמודים | 6–10 עמודים, ממוספר עם גרסה |

**מעבר אוטומטי למסלול המעמיק** — המערכת לא מציגה מספר "בטוח" במסלול הראשוני כשאחד מאלה נכון:
- סוג נכס: צמוד קרקע (קוטג׳, דו-משפחתי, בית פרטי), מגרש, מסחרי או תעשייה.

## 8. מנוע החישוב

### 8.1 בדיקה ראשונית
1. **מעגלי חיפוש:** בניין (גוש/חלקה) → רחוב ±10 מספרים → שכונה → רדיוס 500 מ׳ → 1 ק"מ. עוצרים ברגע שיש ≥ 6 עסקאות.
2. **סינון:**
   - אותו סוג.
   - חדש מול יד שנייה בנפרד.
   - חדרים ±1, שטח ±25%.
   - 36 חודשים.
   - **חלק נמכר = 1**.
3. **עסקה לא-שוק** — מסומנת ולא נכנסת לחישוב:
   - ₪/מ"ר שסוטה ביותר מ-40% מחציון הרחוב/השכונה.
   - חלק נמכר < 1.
   - מוכר וקונה עם אותו שם משפחה (אם המידע זמין).
   - **(זה היה פותר את ממצא 2 בדירובוט.)**
4. **הצמדה:** כל עסקה × (מדד הלמ"ס היום ÷ מדד בחודש העסקה).
5. **₪/מ"ר:** חציון, P25 ו-P75 → **טווח = שטח × P25 … P75**.
   - **שווי אחד בלבד** = שטח × חציון. אין שני מספרים סותרים.
6. **התאמות קלות** (כל אחת מוצגת כשורה, וניתנת לכיבוי):
   - קומה: ±1.5% לקומה מעל/מתחת לחציון קומות העסקאות, עד ±6%.
   - קרקע עם גינה: +5%.
   - בלי מעלית מקומה 3: −3%.
   - הערכים בהגדרות, ומסומנים "לכייל".
7. **ביטחון:**
   - **גבוה** — ≥ 8 עסקאות מבניין/רחוב ב-24 חודשים, ופיזור P75/P25 ≤ 1.2.
   - **בינוני** — 4–7 עסקאות או מעגל שכונה.
   - **נמוך** — מתחת ל-4, או פיזור > 1.35 → הודעה "מומלצת בדיקה מעמיקה".
8. **אחוז מימון** = הלוואה ÷ **P25** (שמרני), מול המגבלה לסוג ההלוואה. ⚠ מגבלות בנק ישראל — **לאמת**.

### 8.2 בדיקה מעמיקה — כמו שמאי
1. **עסקאות דומות עם התאמות פרטניות** לכל עסקה, בדיוק כמו בתחשיב של השמאות מ-2021:

   | התאמה | ערך ברירת מחדל |
   |---|---|
   | הפרש שטח בנוי | ₪/מ"ר בנוי לאזור |
   | חצר / מגרש | משקל 0.2 × ₪/מ"ר בנוי |
   | עליית גג / מרתף | ~50% מ-₪/מ"ר בנוי |
   | גיל ומצב | הנחה מוגדרת |
   | מועד העסקה | מדד הלמ"ס |

   הערכים בהגדרות, וכל עסקה מקבלת **שווי מתואם**. משקל לכל עסקה לפי קרבה ועדכניות → **שווי משוקלל**.
2. **צמוד קרקע: גישת עלות** (כמו ב-2026): **יתרת שווי קרקע** (מעסקאות מגרשים, או שווי × שיעור קרקע) + **ערך כינון** (מ"ר × עלות בנייה ל-מ"ר מטבלה בהגדרות) − **ירידת ערך** לפי גיל.
3. **יישוב:** בין שתי הגישות — **ההבדל ביניהן מוצג**. אם הוא מעל 15%: "פער בין הגישות — לבדוק".
4. **הפחתות:** עלות התאמה להיתר (מ"ר חריגים × עלות), כשיש חריגה.
5. **נספח בטחונות** (כמו 2021):
   - שווי − מימוש מהיר (15%) − הוצאות מכירה (3%) − היטל השבחה צפוי − מס שבח צפוי − עלות התאמה להיתר − **שעבודים קיימים** = **שווי נטו כבטוחה**.
6. **ערך כינון לביטוח** = מ"ר בנוי × עלות בנייה.

## 10. הדוח — מבנה (שני דוחות לדוגמה מצורפים ב-PDF)

### 10.1 דוח בדיקה ראשונית (2–3 עמ׳)
1. **כותרת:** הר-אל, מספר דוח, גרסה, תאריך, מי הפיק, "הערכה פנימית — אינה שומה".
2. **מיקום:** מפה + Street View של הבית + גבולות חלקה (GovMap).
3. **פרטי נכס + שווי:**
   - **שווי אחד**, טווח P25–P75, ₪/מ"ר.
   - ביטחון: גבוה / בינוני / נמוך, עם הסבר במשפט.
4. **עסקאות שנבחרו:** טבלה — כתובת, תאריך, חדרים, מ"ר, קומה, מחיר, מחיר מוצמד, ₪/מ"ר, מעגל (בניין / רחוב / שכונה).
   - **עסקאות שנפסלו — עם סיבה.**
5. **חדש מול יד שנייה:** חציון ₪/מ"ר לכל אחד + **פרויקטים של יזמים באזור**.
6. **אחוז מימון:**
   - ההלוואה, P25, אחוז, המגבלה לסוג ההלוואה.
   - הון עצמי חסר, אם יש.
   - החזר חודשי משוער לפי ריבית ממוצעת של בנק ישראל.
7. **שכירות** (אופציונלי): טווח לפי הלמ"ס, וחוזים מהתיק.
8. **מה לא נבדק כאן**, וכפתור "עבור לבדיקה מעמיקה".

### 10.2 דוח בדיקה מעמיקה (6–10 עמ׳)
1. כל מה שבדוח הראשוני.
2. **זיהוי ורישום:** גוש/חלקה, סוג זכויות, חלק, שעבודים — מתוך מסמכים שאושרו.
3. **תכנון:** תב"עות, ייעוד, זכויות בנייה, זכויות לא מנוצלות.
4. **רישוי:** היתרים, חריגות, עלות התאמה.
5. **תחשיב השוואה עם התאמות:** טבלה לכל עסקה — מחיר → התאמות → מתואם → משקל.
6. **גישת עלות** (צמוד קרקע): קרקע + כינון − פחת.
7. **השומה הפנימית:**
   - שווי.
   - מימוש מהיר.
   - ערך כינון.
   - מס שבח והיטל השבחה צפויים.
   - **שווי נטו כבטוחה**.
8. **דגלים — "מה השמאי ימצא"**, כל אחד עם מה לעשות ("להשיג תשריט חתום", "להציג הסכם הארכה").
9. **מקורות:** רשימה מלאה עם תאריך לכל מקור. אם יש שמאות קודמת בתיק — השוואה אליה.

**מה מעל דירובוט, בשורה אחת:**
- שווי אחד בלי סתירות.
- עסקאות לא-שוק נפסלות עם סיבה.
- חדש מול יד שנייה + מחירונים של יזמים.
- אחוז מימון ובטוחה נטו לפי מגבלות בנק ישראל.
- דגלים משפטיים ותכנוניים לפני השמאי.
- כיול מול שמאויות אמיתיות.

| **קצב עסקאות** | עסקאות ברבעון האחרון מול הממוצע — שוק פעיל או קפוא | מרשם |
| **פער מבוקש / נמכר** | חציון המודעות שאושרו מול חציון העסקאות באותו אזור וגודל | מודעות + מרשם |
| **היצע** | כמה מודעות דומות נמצאו בחיפוש עכשיו | חיפוש |
| **ריבית** | ריבית משכנתא ממוצעת אחרונה ושינויה | בנק ישראל |
| **סיכום של שורה** | "שוק יציב / מתקרר / מתחמם" + הסבר במשפט | Claude, מנתונים אלה בלבד |

### 13.4 "מה יכול להשפיע" — סריקת השפעות

Claude מריץ חיפושים ממוקדים על הכתובת והשכונה, ומחזיר **רשימת גורמים עם מקור לכל אחד:**

| גורם | חיפוש / מקור | כיוון |
|---|---|---|
| התחדשות עירונית (תמ"א 38, פינוי-בינוי) בבניין או ברחוב | מנהל התכנון, הרשות להתחדשות עירונית, חדשות מקומיות | ⬆ פוטנציאל |
| תב"ע חדשה באזור (בנייה רוויה, מסחר) | מנהל התכנון, ועדה מקומית | ⬆/⬇ |
| תחבורה: רכבת קלה או תחנת רכבת בהקמה | נת"ע, חדשות | ⬆ |
| מטרדים: קו מתח, אנטנה, אזור תעשייה, כביש מהיר, נתב"ג | GovMap, חדשות | ⬇ |
| בית ספר / פארק / קניון חדש | עירייה, חדשות | ⬆ |
| הפקעה או דרך מתוכננת דרך החלקה | תב"ע | 🔴 |

**כללים:**
- כל גורם מוצג **עם קישור למקור**. גורם בלי מקור = לא מוצג.
- **הגורמים לא משנים את השווי אוטומטית** — הם רשימה לשאלות ולדוח. רק גורם שאושר ע"י אדם ויש לו ערך בטבלת ההתאמות נכנס לחישוב.

### 13.5 שאלות המשך — "עוד כמה שאלות, ואז הערכה"

**הזרימה:**
1. **4 שאלות** (כתובת, סוג, חדרים, מ"ר) → **הערכה ראשונה + טווח רחב** + תמונת שוק (13.3) + גורמים (13.4).
2. המערכת בוחרת **5–8 שאלות המשך** — אלה שמשפיעות הכי הרבה על השווי **בנכס הזה**: ההתאמה הכי גדולה × אי הוודאות הכי גדולה.
3. **אחרי כל תשובה:** השווי מתעדכן במקום, והטווח מצטמצם. רואים "+3.5% · שופץ ברמה גבוהה".
4. **בסוף: גרף מפל** — שווי בסיס → כל התאמה בשורה → שווי סופי, וטווח צר יותר.

**מאגר שאלות ההמשך** (ערכים התחלתיים — לכיול מול שמאויות אמיתיות, סעיף 8.4):

| שאלה | אפשרויות | התאמה התחלתית ⚠ לכייל |
|---|---|---|
| רמת גמר / שיפוץ | לא שופץ · שיפוץ רגיל · **שופץ ברמה גבוהה (משודרג)** · דרוש שיפוץ | 0 / +2% / +5% / −6% |
| קומה + מעלית | קרקע · ביניים · עליונה · גג; מעלית כן/לא | ±1.5% לקומה; בלי מעלית מקומה 3: −3% |
| חניה | רשומה בטאבו · לא רשומה · אין | +4% / +2% / 0 (באזורים צפופים יותר) |
| ממ"ד | כן / לא | +3% / 0 |
| מרפסת | אין · עד 10 מ"ר · 10+ · מרפסת שמש | לפי מ"ר × 0.3–0.5 מ-₪/מ"ר בנוי |
| מחסן | כן / לא | סכום קבוע לאזור |
| כיווני אוויר / נוף | 1 / 2 / 3; נוף פתוח | 0 / +1% / +2%; נוף +2–5% |
| מצב הבניין | חדש · מתוחזק · ירוד | +2% / 0 / −4% |
| מטרד ידוע | כן (מה) / לא | −2% עד −8% |
| ייחוד | דירת גן · דופלקס · פנטהאוז | מודל נפרד, לא אחוז |
| **רק במסלול המעמיק** | זכויות, היתרים, חריגות (סעיף 5.2) | הפחתות ודגלים |

**איך בוחרים את השאלות:**
- **לא שואלים** מה שכבר ידוע — מהתיק, מהנסח, או מנתוני הבניין במרשם (שנת בנייה, קומות).
- **כן שואלים** מה שבעסקאות הדומות שונה מאוד. למשל: כל העסקאות בבניין עם מעלית, ובנכס לא ידוע → שאלת מעלית עולה ראשונה.
- **"לא יודע"** = לא משנה את השווי, ומשאיר את הטווח רחב.

### 13.6 שמאות עדכנית — לא חד-פעמית

- **כל הערכה נשמרת עם תאריך.** פעם בחודש, ג'וב (לרשום ב-ADDENDUM) מעדכן לפי המדד המקומי והלמ"ס את כל הנכסים בתיקים פתוחים, ואת **לקוחות העבר שמחזיקים משכנתא דרככם**.
- **התראה כשאחוז המימון של לקוח עבר ירד** מתחת לסף. למשל: "שווי הנכס עלה 12% מאז הביצוע → אחוז מימון 58% → אפשר מחזור בתנאים טובים יותר".
  - זה מתחבר ישירות ל**מחזור הלוואות** בתוכנית הכללית: הזדמנות מכירה.
- כל עדכון = שורה חדשה. רואים גרף שווי לאורך זמן לכל נכס.
